# PIA - Tarea 1: Hola Mundo en GitHub

Repositorio creado para la **Tarea 1** del módulo *Programación de Inteligencia Artificial (PIA)* del Curso de Especialización en Inteligencia Artificial y Big Data (CIDEAD, curso 2026/2027).

## Objetivo de la tarea

1. Crear una cuenta en **GitHub** y un primer repositorio.
2. Añadir este archivo `README.md`, escrito en lenguaje de marcado **Markdown**, con una breve explicación de la tarea.
3. Subir un programa sencillo **"Hola Mundo"** escrito en **Python**.
4. Conectar con la comunidad de IA en redes sociales (X o LinkedIn).

## Contenido del repositorio

| Archivo | Descripción |
|---------|-------------|
| `README.md` | Explicación de la tarea (este archivo) |
| `hola_mundo.py` | Programa "Hola Mundo" en Python |

## Cómo ejecutar el programa

```bash
python hola_mundo.py
```

Salida esperada:

```
¡Hola Mundo!
```
